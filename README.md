This project hosts the self-contained `invitation.html` inside a Next.js app so it can be deployed to cloud platforms like Vercel.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The homepage (`/`) renders `invitation.html` through React/Next.js without modifying the original HTML file.

## Learn More

Useful scripts:

- `npm run dev` – start local server
- `npm run lint` – run ESLint
- `npm run build` – create production build
- `npm run start` – run production build

## Deploy on Vercel

The easiest way to deploy is the [Vercel Platform](https://vercel.com/new).

Check out our [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
